# KiwiKids NZ

KiwiKids NZ is a production-style technology platform designed to help New Zealand families discover, compare, and navigate childcare, schools, activities, and education pathways from birth through Year 13.

## Current Phase

Project foundation and local DevSecOps environment.

## Planned Technology Stack

- Next.js + TypeScript
- FastAPI + Python
- PostgreSQL
- Redis
- n8n
- Docker / Docker Compose
- Terraform
- GitHub Actions
- Azure
- Cloudflare
- Prometheus / Grafana / OpenTelemetry
- DevSecOps security scanning and supply-chain controls

## Engineering Principles

- Security by design
- Infrastructure as Code
- Automated CI/CD
- Least privilege
- Observability by default
- Backup and recovery testing
- HA-ready architecture
- Cost-conscious cloud design
- Privacy-focused handling of family data
